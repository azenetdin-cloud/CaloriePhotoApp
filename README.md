# Калории по фото — версия 3.0

Добавлена история питания: результаты распознавания сохраняются на телефоне и доступны после перезапуска приложения.

Функции:
- камера и галерея;
- настоящее распознавание еды через Gemini 2.5 Flash;
- оценка веса порции;
- калории и Б/Ж/У;
- сохранение до 100 последних записей;
- просмотр истории;
- очистка истории;
- API key сохраняется локально в настройках приложения.

Важно: оценка веса и калорий по фотографии приблизительная.
