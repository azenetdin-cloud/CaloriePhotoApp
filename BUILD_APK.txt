КАК ПОЛУЧИТЬ APK БЕЗ ANDROID STUDIO

1. Создайте бесплатный аккаунт на GitHub.
2. Создайте новый репозиторий, например CaloriePhotoApp.
3. Распакуйте этот ZIP.
4. Загрузите ВСЕ файлы проекта в репозиторий.
5. Откройте вкладку Actions.
6. Выберите workflow «Build Android APK».
7. Нажмите Run workflow.
8. После завершения откройте готовый запуск workflow.
9. Внизу страницы скачайте artifact «CaloriePhotoApp-v3.0-apk».
10. Внутри будет app-debug.apk — его можно установить на Android.

В приложении уже есть:
- камера;
- выбор фото;
- распознавание еды через Gemini;
- калории и Б/Ж/У;
- история питания до 100 записей;
- очистка истории.

Для AI нужен Gemini API key. Не публикуйте ключ в открытом репозитории.
